## Sobre mí

Diseño, construyo y opero **automatizaciones con n8n + IA** para empresas: captación, seguimiento
de ventas y operaciones internas que corren todos los días sin supervisión.

- 🤖 **Chatbots y WhatsApp** — atención automática, reactivación de oportunidades, handoff a humanos
- 📋 **Pipelines de ventas** — colas de llamados para SDRs sincronizadas con el CRM en minutos
- 🧠 **IA dentro de la operación** — resúmenes, propuestas, respuestas automáticas, bots de voz y documentos
